# Python Automation Script

## Objective
This project automatically organizes files into folders based on file type.

## Features
- Organizes Images, PDFs, Text, Audio files
- Creates folders automatically
- Uses logging
- Handles exceptions
- Takes user input

## Technologies Used
- Python
- OS Module
- Shutil
- Logging

## How to Run

```bash
python main.py
```

## Sample Output

Moved karthik.jpeg to Images
Moved CODE 2.txt to Text

Task completed successfully.
